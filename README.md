# MovieFlix - Modern Movie Streaming Website

A sleek and modern movie streaming website built with HTML, CSS, and JavaScript. Features a responsive design, beautiful animations, and an interactive user interface.

## Features

- 🎬 Modern and responsive UI design
- 🔍 Real-time search functionality
- 🎯 Category filtering system
- ⭐ Movie ratings display
- 💫 Smooth animations and transitions
- 📱 Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Modern Animation Techniques

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Start exploring movies!
